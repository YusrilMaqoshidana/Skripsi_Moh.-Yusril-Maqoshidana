\frontmatterchapter{ABSTRACT}

% --- ISI ABSTRACT ---
\noindent High message activity in WhatsApp groups frequently causes information overload, making it challenging for users to track discussions and extract key insights without manually reading lengthy chat histories. While topic modeling can automate thematic extraction, applying it to WhatsApp conversations presents substantial challenges due to short text length, informal grammar, noise, and code-mixing. Furthermore, the standard BERTopic framework relies on HDBSCAN clustering, which inherently discards 41\%--43\% of messages as outliers, causing critical conversational data loss.

This study aims to develop an enhanced BERTopic architecture that integrates the IndoBERTweet embedding model, BIRCH hierarchical clustering to minimize outlier rates, and the BM25 weighting scheme for topic keyword representation. The model is evaluated against the baseline BERTopic using Topic Coherence (C-NPMI), Topic Diversity, Embedding Density, and Intra-topic Similarity, and is implemented into an end-to-end web-based analytics platform.

The research employs an experimental and R\&D methodology utilizing 91,868 raw messages from the ``Komunitas Buku'' WhatsApp group (2023--2026), producing 51,584 clean documents via Single-Path Preprocessing. The topic modeling pipeline incorporates IndoBERTweet (768-d), UMAP reduction (5-d), BIRCH clustering (\textit{ImprovedBirch}), BM25 keyword representation with a 9-category stopword filter, and automatic topic reduction. The system is built on a client-server architecture (Vue.js and FastAPI) featuring real-time SSE progress streaming, message context traceability, and client-side privacy preservation.

Quantitative $2 \times 2$ factorial learning curve evaluation demonstrates the comprehensive superiority of the proposed model. The proposed \textit{ImprovedBirch} algorithm restricts the outlier rate to 7.21\% on 51,584 documents (retaining 92.79\% data coverage), substantially outperforming HDBSCAN-based baselines (42.47\%--56.66\%) and overcoming reference journal model limitations that lack topic reduction. Integrating IndoBERTweet and BM25 achieves a positive semantic coherence ($C_{\text{NPMI}}$) of +0.1075 and the highest Topic Diversity of 0.9875 compared to baseline and reference journal models. Black-box testing confirms that all web features operate with 100\% validity, verifying that the proposed architecture effectively extracts cohesive, diverse, and robust WhatsApp conversation topics with minimal information loss.
